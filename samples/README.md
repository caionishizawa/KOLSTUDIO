# samples/

Arquivos de teste reais (não versionados no git, só a estrutura).

```
samples/
  react/
    clipe.mp4     # vídeo de outra pessoa falando, com áudio
    reacao.mp4    # seu rosto reagindo em silêncio
  takes/
    take1.mp4, take2.mp4, ... take10.mp4   # um por frase (ordem natural)
  imagens/
    1.png, 2.png, 3a.png, 3b.png, extra.png # número no nome = take
  musica/
    musica.mp3
```

Arraste a pasta `samples/` inteira na área "Arraste uma pasta inteira aqui" do app.
A classificação usa a subpasta e o nome (`clipe*`, `reacao*`, `takes`, `imagens`, `musica`).
